The small print

Studio originals.

RotDeck's starter pack contains original spoken reactions and a code-generated cartoon shout: Six Seven, FAAAAAH!, Brain Cell Roll Call, Buffering, Caffeine Court, Scribble Mode, Flash Step, Tra La La, Tiptoe Mode, and Boo. No downloaded meme recordings, song excerpts or copied melodies are included.

Generated voices

Original voice performances were generated locally using the Kokoro-82M model, whose weights are published under Apache License 2.0. The generation tool uses kokoro-onnx under the MIT License. The model, voice weights, and generation runtime are not bundled with the iPhone app.

Original effect and artwork

FAH is an original sustained cartoon shout made from seeded synthesis, a written pitch contour and vowel resonances. No voice recording is sampled. The app icon, custom illustrations, interface and waveforms are created for RotDeck; some pad symbols use Apple's system symbol library.

Sharing

All ten Studio originals can be shared and combined. Permission covers personal or commercial use, modification and redistribution of this original audio.
